# Gym Companion · Android

WebView shell for the bundled web app in `app/src/main/assets/gym/` (generated by `../tools/build.sh`).
Served through `WebViewAssetLoader` on `https://appassets.androidplatform.net`, so there is no `file://`
access; data lives in the WebView's IndexedDB, with no cloud backup (device-to-device transfer allowed).

Build from the repo root: `tools/build.sh --apk`. Release signing reads a properties file outside the repo
(`GYM_KEYSTORE_PROPS`, see `app/build.gradle.kts`); without it the release APK is unsigned.
